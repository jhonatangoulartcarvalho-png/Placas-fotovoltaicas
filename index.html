    Ondas eletromagnéticas

    Toda onda eletromagnética viaja no vácuo a c = 3×10⁸ m/s. As relações são c = λ·f e E = h·f. Quanto menor o comprimento de onda, maior a energia do fóton.

    Relação com o projeto
    FaixaPapel na piscina
    UltravioletaDegrada a cloração e a capa; pode ativar painéis fotovoltaicos.

    Radiação do corpo negro

    Todo corpo com temperatura acima do zero absoluto emite radiação. A lei de Wien dá o pico: λmax = 2898 µm·K / T. A potência total por área segue Stefan-Boltzmann: P/A = σT⁴, com σ = 5,67×10⁻⁸ W/m²K⁴. Planck descreve a curva completa.

    Conexão: o Sol (pico no visível) aquece o coletor escuro, que absorve bem essa luz. A piscina, a ~28 °C, emite no infravermelho distante (pico perto de 10 µm), por isso perde calor para o céu limpo à noite. A capa térmica bloqueia essa troca.

    Efeito fotoelétrico

    Um fóton só arranca um elétron se h·f ≥ φ (função trabalho). A energia cinética máxima é Ec = h·f − φ. Aumentar a intensidade aumenta o número de elétrons (corrente), não a energia de cada um.

    Conexão: numa célula fotovoltaica, fótons soltam elétrons no silício (efeito fotoelétrico interno). A eletricidade gerada pode alimentar a bomba de circulação ou uma bomba de calor.

    Projeto da Piscina

    Modelo simplificado e didático: perda radiante P = ε·σ·A·(Tágua⁴ − Tcéu⁴) com ε = 0,96; a capa reduz essa perda em cerca de 85% (valor assumido). Não inclui evaporação, convecção e condução, que também diminuem com a capa. Coletor com eficiência de 60%, painel de 20% e bomba de calor com COP 4, todos assumidos.

    Robótica: sensores e automação

    Um microcontrolador (Arduino, ESP32) lê sensores e decide. Mova os controles para simular o ambiente.

    Código de exemplo (C++/Arduino)

    void loop() {
  float G  = lerLuz();          // W/m²
  float Tc = lerTempColetor();  // °C
  float Tp = lerTempPiscina();  // °C
  bool bomba = (G > 200) && (Tc > Tp + 5);
  bool capa  = (G < 50);        // noite: fecha a capa
  digitalWrite(PINO_BOMBA, bomba);
  digitalWrite(PINO_CAPA, capa);
  delay(5000);
}

    Inovação: a histerese (5 °C) evita liga-desliga constante, e a capa fecha sozinha ao anoitecer, automatizando a economia de energia.
